# Tic Tac Toe Game

A simple, responsive Tic Tac Toe game built with vanilla HTML, CSS, and JavaScript — featuring a clean, modern dark-themed UI.

## ✨ Features

- Classic 2-player Tic Tac Toe (Player O goes first)
- Automatic win detection across all 8 winning patterns (rows, columns, diagonals)
- Draw detection when the board fills up with no winner
- "New Game" and "Reset Game" options
- Responsive board sizing using `vmin` units — works on both desktop and mobile
- Modern dark UI with gradient accents and smooth hover animations

## 🛠️ Tech Stack

- **HTML5** – structure
- **CSS3** – styling, gradients, and animations
- **JavaScript (Vanilla)** – game logic

## 🚀 How to Run Locally

1. Clone or download this repository
2. Open `index.html` in any modern web browser
3. Start playing — no build steps or dependencies required

## 🕹️ How to Play

1. Player **O** clicks a box first, then Player **X** takes the next turn
2. Turns alternate until a player gets 3 in a row (horizontally, vertically, or diagonally) or the board fills up
3. Click **New Game** or **Reset Game** to play again
